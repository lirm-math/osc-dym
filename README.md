# osc-dym

Numerical verification of the `solve_dym` libraries (`libsolve_dym_<x>.a`, with `x = 4, 8, 10, 16`), which construct oscillatory solutions to the **Harry Dym equation**. This repository provides example usage of the libraries and demonstrates how rounding errors affect the numerical residuals.

## Description

This project numerically verifies that the oscillatory solutions generated by the `solve_dym` libraries satisfy the Harry Dym equation:

\[
r_t = \frac{1}{2} r^3 r_{xxx}.
\]

The implementation computes the solution at given grid points, evaluates its numerical derivatives, and checks the residual of the PDE. The code is tested under **Ubuntu 24.04** with **g++ 13**. Users are expected to compile and run the code on a similar platform.

This work is part of the paper:

> **Enhanced Darboux transformations and Oscillatory \(N\)-cuspon solutions of the Harry Dym equation**  
> by LI Ruomeng, GENG Xianguo, XUE Bo, and LI Yihao  
> [Journal and DOI to be updated upon publication]

The project serves as supporting material, providing numerical evidence of the correctness of the derived formulae. It also allows readers to generate and visualize additional solutions beyond those presented in the publication, and to observe how rounding errors influence the residual \(\epsilon\).

## Features

- Example usage of the `solve_dym` libraries.
- Verification of oscillatory solution properties.
- Easy integration with user code via static libraries.
- Generation of numerical data for further analysis and plotting.
- Demonstration of the effect of rounding errors on numerical derivatives.

## Dependencies

- **Operating system:** Ubuntu 24.04 (or a compatible Linux distribution). The code may work on other platforms with appropriate modifications.
- **Compiler:** g++ 13 or later (supporting C++20).
- **Build tool:** GNU Make.
- **Boost libraries** (optional, but required for `REAL_16` mode): The library uses `boost::multiprecision::cpp_float_bin_quad` when compiled with `-DREAL_16`.
